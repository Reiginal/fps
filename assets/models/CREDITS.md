# ここに置いてあるモデルの出どころ

**今は1つも置いていない。**

一度 Quaternius の GunPack Vol.1（CC0）のライフルを置いてみたが、
**構えて見比べたら、コードで組んだ物のほうが明らかに良かった**ので外した。

| | 三角形 | 見た目 |
|---|---|---|
| コードで組んだライフル | — | スコープ・機関部・弾倉・肌理がある |
| 置いてみたCC0のライフル | 676 | 単色。細い棒に見える |

**「買った（もらった）モデルに替える＝良くなる」ではない。**
無料で配っている物は、その形の中では良く出来ていても、
このゲームの銃のように「目の前に大きく映る1個」に耐える密度は無いことが多い。

次に試すなら、**三角形が数千あって、色（テクスチャ）が付いている物**を見る。
無料の範囲だと難しいので、そこは買う話になるかもしれない。

## 置き方

ファイルを `assets/models/<武器のid>.glb` に置いて、
`src/player/glbview.js` の `HAS_MODEL` に名前を1行足す。
**両方やらないと `tools/check-weapons.mjs` が落ちる**（片方だけだと、
読みに行かない／404が出る、のどちらかになるため）。
