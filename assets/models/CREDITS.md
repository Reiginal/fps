# ここに置いてあるモデルの出どころ

|---|---|---|---|
| rifle.glb | GunPack Vol.1 の Rifle | Quaternius | **CC0**（何をしてもいい。表示も義務ではない） |

- 取ってきた所: https://opengameart.org/content/low-poly-guns
- 元はOBJだったので、glbへ変換して色を付けた（三角形676、67KB）
- 同じパックの ak47 も試したが、**箱の比率が銃らしくなかった**（2.97 x 1.17 x 1.69）ので
  Rifle のほう（0.42 x 1.23 x 8.77）にした。細長い物でないと、構えた時に板に見える

CC0は「著作権を放棄した」という宣言なので、**表示の義務は無い。**
それでもここに書いてあるのは、後から「これどこから持ってきたんだっけ」に
必ずなるため。素材を足したらここに1行足すこと。
