# BLACKOUT

[![CI](https://github.com/Reiginal/fps/actions/workflows/ci.yml/badge.svg)](https://github.com/Reiginal/fps/actions/workflows/ci.yml)

ブラウザで遊ぶFPS。

## 遊ぶ

**https://blackout-fps.fly.dev**

開くと1人で遊ぶか対戦かを選ぶ画面が出る。画面をクリックするとマウスが固定されて始まる。抜けるときはESC、もう一度クリックすれば戻る。

1人用は敵を全滅させると次のウェーブが来て、波が進むごとに敵が増えて強くなる。倒すと100点、ヘッドショットは250点。

対戦は名前を入れて「対戦に参加」を押すだけ。開いた人は全員同じロビーに集まるので、URLを送ればそのまま合流できる。ロビーで空いている席に座り、座った全員が準備完了を押すと始まる。

**2人から4人まで。チーム分けは無く、座った人全員が互いに敵になる。** 最後まで残った人がそのラウンドを取り、先に3ラウンド取った人が勝ち。ロビーでは見た目も選べる。

ロビーでも試合中でもEnterで発言できる。

## 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| Shift | スプリント（前進中のみ） |
| C / Ctrl | しゃがみ |
| Space | ジャンプ |
| 左クリック | 射撃 |
| 右クリック | 覗き込み |
| R | リロード |
| 1 / 2 / 3 / 4 | ライフル / ショットガン / ナイフ / 手榴弾 |
| F | 包帯を取り出す（出したあと左クリックで巻く） |
| Enter | 発言（対戦中） |
| Tab | 戦績表（対戦中、押している間だけ） |
| ESC | 一時停止 |

止まって覗いてから撃つのが一番当たる。移動中・ジャンプ中は弾がばらける。クロスヘアの開き具合が実際のばらつき角そのものなので、閉じてから撃つ。
