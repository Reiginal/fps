# BLACKOUT

[![CI](https://github.com/Reiginal/fps/actions/workflows/ci.yml/badge.svg)](https://github.com/Reiginal/fps/actions/workflows/ci.yml)

ブラウザで遊ぶFPS。

## 遊ぶ

**https://blackout-fps.fly.dev**

開くと1人で遊ぶか対戦かを選ぶ画面が出る。画面をクリックするとマウスが固定されて始まる。抜けるときはESC、もう一度クリックすれば戻る。

1人用は敵を全滅させると次のウェーブが来て、波が進むごとに敵が増えて強くなる。倒すと100点、ヘッドショットは250点。

対戦は名前を入れて「対戦に参加」を押すだけ。開いた人は全員同じロビーに集まるので、URLを送ればそのまま合流できる。ロビーで空いている席に座り、座った全員が準備完了を押すと始まる。

**2人から4人まで。** ロビーで遊び方・席・見た目を選ぶ。

| 遊び方 | 中身 |
|---|---|
| デスマッチ | 座った人全員が互いに敵。最後まで残った人がそのラウンドを取る。先に3ラウンドで勝ち |
| ガンゲーム | 倒すたびに武器が替わる。全部の武器で1回ずつ倒したら勝ち |
| 2対2 | 左の2席と右の2席でチーム。**味方は撃てない。** 先に3ラウンドで勝ち |

倒れた人はその場に武器と残りの手榴弾を落とす。踏むと弾と手榴弾が戻る（デスマッチと2対2）。

**回線が切れても60秒以内に戻れば、席と点数を持って続きから遊べる。** 入り直すのは自動。

ロビーでも試合中でもEnterで発言できる（対戦だけ）。
**Vを押している間は味方に声が届く**（マイクの許可を最初に1度だけ聞かれる。断っても遊べる）。

## 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| Shift | スプリント（前進中のみ） |
| C / Ctrl | しゃがみ |
| Space | ジャンプ |
| 左クリック | 射撃 |
| 右クリック | 覗き込み |
| R | リロード |
| 1 / 2 / 3 / 4 | ライフル / ピストル / ナイフ / 手榴弾 |
| F | 包帯を取り出す（出したあと左クリックで巻く） |
| P | 今の画面をクリップボードへコピー |
| Enter | 発言（対戦中） |
| V | 押している間だけ味方に話す（対戦中） |
| Tab | 戦績表（対戦中、押している間だけ） |
| ESC | 一時停止 |

止まって覗いてから撃つのが一番当たる。移動中・ジャンプ中は弾がばらける。クロスヘアの開き具合が実際のばらつき角そのものなので、閉じてから撃つ。

遊びに来た時刻で空が変わる（朝・昼・夕方）。ホーム画面から設定（感度・音量）と戦績（通算と実績）が開ける。
