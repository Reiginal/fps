# BLACKOUT

[![CI](https://github.com/Reiginal/fps/actions/workflows/ci.yml/badge.svg)](https://github.com/Reiginal/fps/actions/workflows/ci.yml)

ThreeJSで作ったブラウザFPS。画像ファイルも音源ファイルも一切持たず、テクスチャと効果音を全部コードで生成している。

## 遊ぶ

```bash
npm install     # 初回のみ
npm start
```

ブラウザで **http://localhost:8080** を開くと、1人で遊ぶか対戦かを選ぶ画面が出る。1人で遊ぶを押して画面をクリックすると、マウスが固定されて始まる。

`npm start`はゲーム本体の配信と対戦の受け口を両方やる。起動口はこれ1つだけなので、1人で遊ぶ時と対戦する時でコマンドを変える必要はない。

抜けるときはESC。もう一度クリックすれば戻る。

> ESモジュールを使っているので、`index.html` をダブルクリックして開く（file://）方法では動かない。必ず `npm start` のサーバー経由で開くこと。

### 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| Shift | スプリント（前進中のみ） |
| Ctrl / C | しゃがみ |
| Space | ジャンプ |
| 左クリック | 射撃 |
| 右クリック | 覗き込み（ADS） |
| R | リロード |
| 1 / 2 / 3 / 4 | ライフル / ショットガン / ナイフ / 手榴弾 |
| F | 包帯を取り出す（出したあと左クリックで巻く） |
| K | キル音を切り替えて試す |
| Tab | 戦績表（対戦中、押している間だけ） |
| ESC | 一時停止 |

### 遊び方のコツ

- **止まって覗くのが一番当たる。** 移動中・ジャンプ中・腰だめは弾がばらける。しゃがむとさらに集まる。クロスヘアの開き具合が実際のばらつき角そのものなので、閉じてから撃つ
- **頭を狙う。** ライフルなら2.4倍、SMGは2.0倍。距離が離れるとダメージが落ちるので、遠いほど頭が要る
- **撃たれた方向は画面中心の赤いリングで出る。** 音より先にこれを見る
- **遮蔽を使う。** 敵は壁越しには当てられない。胸の高さの遮蔽と全身が隠れる遮蔽が混ざって置いてある
- **弾切れは自動でリロードが走る**が、待つと死ぬ。撃ち終わりにRを押しておく
- 弾が耳元を掠めると音が鳴る。近い

### ゲームの流れ

敵を全滅させると次のウェーブが来る。波が進むごとに敵の数・体力・命中精度・移動速度が上がる。倒すと100点、ヘッドショットは250点。

死ぬと戦績（スコア・到達ウェーブ・キル数・ヘッドショット数・命中率）が出て、クリックでやり直せる。

武器は4つ。アサルトライフル（フルオート、中距離）、ショットガン（9発の散弾、ポンプアクション）、ナイフ（近接、持っている間だけ速く走れる）、手榴弾。銃は反動パターン・ばらつき・距離減衰・ADS時の倍率が別々に設定してある。

## 対戦する

1対1。**1回死んだらそのラウンドは終わり**で、先に3ラウンド取った方が勝ち。1ラウンドは90秒。

中央から半径20mの外へ出ると体力が減り続けるので、広いマップでも必ず出会う。ラウンドの頭では湧く位置が固定で、体力・弾薬・包帯・手榴弾が戻る。

2人揃うまでは待機になる。

### 立てる

誰か1人がサーバーを立てる。

```bash
npm start
```

1人で遊ぶ時と同じコマンド。これ1本でゲーム本体の配信と対戦の両方をやる。

### 参加する

立てた人の画面に出ているURLを開いて、選択画面で名前を入れて「対戦に参加」を押す。

| どこで遊ぶか | 接続先に入れる値 |
|---|---|
| 立てた本人 | 既定のまま（`ws://localhost:8080`） |
| 同じWi-Fi内 | 立てた人のIPに書き換える（`ws://192.168.1.24:8080` のような形） |
| インターネット越し | サーバーを外に置いて、そのアドレス |

立てた人のIPは、macなら `ipconfig getifaddr en0`、Windowsなら `ipconfig` で出る。

**合言葉**は部屋を分けるための4文字。同じ合言葉を入れた人だけが同じ試合に入る。空のままなら全員が共通の部屋に入るので、身内だけで遊ぶなら空でいい。

インターネット越しでやるなら、サーバーを置いた場所のポート（既定8080）を開ける必要がある。`PORT=3000 npm start` のようにポートは変えられる。

### 対戦の作り

**当たったかどうかを決めるのはサーバー**で、各自のブラウザではない。ブラウザが送るのは「押しているキー」と「向いている方向」だけで、座標は一切送らない。座標を送らせると、送る側が好きな値を書けてしまって壁抜けし放題になる。

サーバーはクライアントとまったく同じ `buildLevel` と同じ `Player` クラスを動かしている。だから地形と移動が食い違わない。マップを直してもサーバー側を焼き直す手間は要らない。

「当てたのに抜ける」への対策も入れてある。あなたの画面に映っている相手は、通信の遅れの分だけ過去の姿なので、サーバーは各プレイヤーの直近0.3秒ぶんの位置を覚えておいて、撃たれた瞬間に「この人の画面ではどこに見えていたか」まで時間を巻き戻してから判定する。

自分の移動は待たずに手元で動かし、サーバーの答えが後から届いてズレていた分だけ静かに直す。他の人は0.1秒遅らせて2つの受信位置の間を補間して描いている。

### アセットを持たない作り

- **テクスチャ**: 値ノイズとボロノイからコンクリート・アスファルト・塗装鉄板・木材・土嚢を合成。同じ高さ場からアルベド・法線・ラフネス・メタルネス・AOを導出しているので、凹凸と光沢が必ず一致する
- **効果音**: WebAudioでノイズとフィルタから合成。銃声は「立ち上がりのクラック」「胴体の低い押し」「尾を引く残響」の3層構造。残響用のインパルス応答も手で生成している
- **空とIBL**: 空はシェーダーで描き、それをPMREMに焼いて環境光にしている
- **モデル**: 銃も兵士も箱と円柱の組み合わせ。アニメーションは手付けせず、全部プログラムで動かしている

### 手触りのために入れたもの

- 反動はバネで戻す。視点の跳ね上がりと銃の跳ね返りを別々に持つ
- 視点を振ると銃が遅れて付いてくる
- 歩くと頭が上下し、その位相で足音が鳴る
- 着地すると沈み込んで戻る
- クロスヘアは実際のばらつき角と連動して開閉する
- 覗き込むと感度が落ちる
- 排莢された薬莢は転がって跳ねて、1回目だけチャリンと鳴る
- 撃たれた方向が画面中心のリングで出る

### 検査

```bash
npm run check     # ブラウザ無しで走る検査（183項目）
npm run lint      # 静的解析
npm run sounds    # 音を sounds/*.wav に書き出して数字で並べる
```

画面を見ないと分からない類の不具合を、ブラウザを開かずに潰すための道具。
武器が画面から見切れていないか、包帯が実際に手に出るか、キル音に低音が入っているか、
呼んでいるメソッドが本当に存在するか、といったことを測って落とす。

`npm run sounds` はゲームを起動せずに音だけ聴き比べるためのもの。

```bash
for f in sounds/kill-*.wav; do echo "$f"; afplay "$f"; sleep 0.7; done
```

## 判定の考え方

移動の衝突判定はカプセルとOctree（`three/addons`）。三角形単位で見ているので、斜路もコンテナの上も特別扱いなしで歩ける。

弾の判定は見た目のメッシュではなく、頭は球・胴と脚はカプセルという専用形状で取る。速いし、当たったはずなのに抜けるということが起きにくい。ヘッドショットは武器ごとの倍率、脚は0.82倍。距離減衰も武器ごとに設定してある。

敵の射撃は「命中するかを先に判定してから、その結果に合う散らばりで弾を飛ばす」方式。ただし必ず遮蔽を確認するので、壁越しには当たらない。

## 分かっている限界

- 敵の経路探索は遮蔽物を避けながらプレイヤーへ向かう単純な操舵。込み入った屋内では詰まることがある（詰まったら小さく跳ねて乗り越える保険は入れてある）
- 死体はしばらく残って薄くなって消える。物理的なラグドールではない
- 対戦中にタブを裏に回すと、ブラウザが描画を止めるので入力が送られなくなり、その場で立ち止まる。撃たれるので戻ってくること
- 対戦の暗号化はしていない。インターネット越しに置くなら、身内に配る前提で使う
